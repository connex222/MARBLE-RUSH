## Integration

- The new `src/modes/party-fx.js` is a **presentation-only** renderer. It uses existing seeded simulation event arrays and never consumes random numbers or writes game-state properties.
- `tools/build.js` includes the renderer in the standalone TV bundle and processes optional `pp_*_fx_*.png` at 384-pixel longest edge.
- `src/tv.js` overlays effects only for Derby, Drop Zone, Brawl, Curling and Golf. Grand Prix is unchanged.
- Effects expire after 1.05 seconds, or 0.30 seconds when reduced-motion is enabled. Rendering is capped at 16 events per frame.
- Missing assets use `drawSprite()` returning `false` and a code-drawn particle fallback. The game can render without any of the 48 PNG files.
- Effect positions are constrained to the playfield to keep the TV score console readable.
